# Решения и их обоснование

## Что взято из AI Newsroom (проверено по его репозиторию, 2026-09-27)

| Аспект | AI Newsroom (факт) | Этот проект | Почему |
| --- | --- | --- | --- |
| LLM | Gemini через Vercel AI SDK (`@ai-sdk/google`), `gemini-flash-lite-latest`; эмбеддинги `gemini-embedding-001` | Gemini REST (httpx), `gemini-3.5-flash-lite` (закреплённая версия); `gemini-embedding-001` | тот же провайдер и класс модели; Python-стек без SDK; закреплённая версия вместо плавающего алиаса `-latest` |
| Планировщик | GitHub Actions cron (Vercel Hobby ограничивает функцию 60 с) | GitHub Actions cron каждые 4 ч | та же проверенная схема |
| БД | Neon (pooled URL + direct URL для миграций) | Supabase (Session pooler) | требование задания; отдельный проект, схема `newsbot` |
| Веб | Next.js на Vercel | FastAPI-панель на Vercel | только read-only мониторинг |
| Векторы | JSON-массивы, косинус в приложении (без pgvector) | так же, 256 измерений | объём БД на Free-тарифе; на сотнях историй в окне pgvector не нужен |

Ничего из AI Newsroom не используется во время работы: ни его БД, ни ключ, ни репозиторий.

## Модель Gemini

Проверено по официальной документации 2026-09-27 (ai.google.dev: models, pricing, rate-limits,
structured-output, available-regions):

- Free tier («Free of charge») есть у Gemini 3.8/3.7/3.6/3.5 Flash, 3.5 Flash-Lite, 3.1 Flash-Lite,
  2.5 Flash/Flash-Lite (2.5 — только для прежних пользователей; новым проектам рекомендованы
  3.5 Flash-Lite или 3.8 Flash). Контент free tier используется Google для улучшения продуктов.
- Конкретные RPM/TPM/RPD free tier Google публикует только в AI Studio → Rate limit; лимиты
  применяются на **проект**, RPD сбрасывается в полночь по тихоокеанскому времени.
- Finland входит в список поддерживаемых регионов.
- Структурированный JSON: `responseMimeType: application/json` + JSON Schema.

Выбор: **`gemini-3.5-flash-lite`** — стабильная, самая дешёвая в своём поколении, с free tier;
AI Newsroom показал, что Flash-Lite даёт наиболее щедрую бесплатную квоту, а `gemini-flash-latest`
упирался в лимиты. Меняется одной переменной `GEMINI_MODEL` (например, на `gemini-3.8-flash` для
лучшего качества текста — ценой меньшей квоты). Подписка на пользовательский Gemini (Google One /
Gemini Advanced) не даёт квоты Gemini API — это разные продукты.

## Сменяемый LLM-слой

`LLMProvider` (base.py) — два метода: `generate_json` и `embed`, плюс классификация ошибок
(`RateLimited`, `QuotaExhausted`, `Transient`, `Permanent`). Всё остальное — в `AIGateway`:
учёт каждой попытки в `llm_calls` (токены из `usageMetadata`), дневной лимит, блокировка после
суточной квоты, паузы, ограниченные ретраи, лимит входа/выхода, валидация Pydantic с одной
попыткой исправления. Новый провайдер = новый класс + строка в `build_provider`. Автоматического
переключения на платную модель нет.

## Дедупликация: честные ограничения

- Косинус эмбеддингов, похожесть заголовков и LLM-проверка серой зоны — эвристики. Идеальной
  семантической дедупликации нет; при сомнении истории НЕ сливаются (лучше редкий дубль, чем
  потерянная новость), а публикационный фильтр сравнивает с уже опубликованным.
- Разные версии («GPT-5» и «GPT-5.1») никогда не сливаются по сходству.
- Пороги `EMBED_MERGE_STRONG/GRAY` откалиброваны на реальных англо-русских парах (см. результаты
  живой проверки в итоговом отчёте) и настраиваются переменными.

## Рейтинг: приближения

- `mentions` — число **разных доменов**, это приближение независимого освещения, а не доказанное
  число независимых подтверждений (издания перепечатывают друг друга).
- `social`/`velocity` — очки и комментарии HN, голоса HF Papers; у RSS-источников соцсигналов нет.
  Популярность ограничена 22 баллами из 100; при `industry_impact ≥ 8` действует «технический пол»,
  чтобы значимое исследование без вирусности не проигрывало.
- Компоненты сохраняются в `stories.score_components` и видны в панели.

## Telegram-аналитика: что реально доступно

Bot API даёт число подписчиков (`getChatMemberCount`) и счётчики реакций в каналах
(`message_reaction_count`, бот должен быть администратором; апдейты хранятся ~24 ч, опрос каждые 4 ч).
Просмотры постов Bot API не предоставляет — они не собираются и не обещаются.
